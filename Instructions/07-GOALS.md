# BudgetPlan — Savings Goals

## Goal List
Each goal shows:
- Icon
- Goal name
- Current amount
- Target amount
- Percentage
- Progress
- Target date

## Goal Detail
Show:
- Current savings
- Target
- Remaining
- Percentage complete
- Target date
- Suggested monthly contribution
- Contribution history

## Savings Calculator
Inputs:
- Target amount
- Current savings
- Deadline

Outputs:
- Required monthly savings
- Required weekly savings
- Required daily savings

## Goal Contribution
Adding a contribution should update the goal balance and contribution history.
