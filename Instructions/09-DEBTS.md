# BudgetPlan — Debt Management

## Debt List
Show:
- Debt name
- Remaining amount
- Progress
- Minimum payment
- Due date

## Debt Detail
Fields:
- Original amount
- Remaining amount
- Minimum payment
- Due date
- Interest rate (optional)
- Payment history

## Add Payment
When a payment is recorded:
- Reduce remaining debt
- Record transaction
- Update progress

## Future Features
- Debt snowball
- Debt avalanche
- Payoff forecast
- Interest estimation
