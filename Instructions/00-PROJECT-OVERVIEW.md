# BudgetPlan — Project Overview

## Product Vision
BudgetPlan is a personal financial planning app that helps users understand:
- How much money they have
- Where their money is going
- How much they can safely spend
- Which bills are due
- How close they are to savings goals
- Whether they are staying within budget

## Core UX Principle
Do not build only an expense tracker. Build a financial planning assistant.

Primary flow:
Income → Plan → Spend → Monitor → Save → Improve

### MVP
Authentication, dashboard, income, expenses, categories, monthly budget, transactions.

### V2
Bills, recurring transactions, savings goals, accounts, transfers, notifications.

### V3
Analytics, debts, financial insights, safe-to-spend, monthly reports, CSV/PDF export.

### V4
AI assistant, receipt OCR, automatic categorization, bank integrations, forecasting.
