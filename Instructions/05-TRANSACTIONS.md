# BudgetPlan — Transactions Module

## Transaction Types
- Income
- Expense
- Transfer

Transfers must not count as expenses.

## Transaction List
Support:
- Search
- Date filter
- Category filter
- Amount filter
- Account filter
- Transaction type filter

## Add Expense
Fields:
- Amount
- Category
- Date
- Payment method/account
- Note
- Optional receipt

## Add Income
Fields:
- Amount
- Source
- Date
- Account
- Recurring toggle
- Frequency

## Transaction Detail
Show:
- Type
- Amount
- Category/source
- Account
- Date
- Note
- Created date
- Edit
- Delete

## Confirmation
After saving:
- Show success state
- Show updated budget remaining
- Return to previous context

## Recurring Transactions
Support:
- Daily
- Weekly
- Bi-weekly
- Monthly
- Yearly
